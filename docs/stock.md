# 보유 자원 UI

게임 화면 오른쪽 위에 배경과 제목 없이 자원 아이콘과 수량만 표시합니다. 목재는 통나무 아이콘으로 구분하고 밝은 숫자에 어두운 외곽선과 그림자를 더해 맵 위에서도 읽기 쉽게 합니다. 표시 높이는 36px이며 오른쪽으로 정렬합니다. `type=0`은 목재이며 처음에는 0입니다. UI는 맵 클릭·드래그를 가로채지 않습니다.

```text
STOCK 0 120
```

`STOCK type amount`의 amount는 증감량이 아닌 현재 총량입니다. 같은 메시지를 다시 받아도 더하지 않으며 소비로 감소하거나 0이 되어도 반영합니다. 서버가 주인에게만 전송하므로 플레이어 ID는 메시지에 필요하지 않습니다. 기존 게임 상태 메시지처럼 WORLD_READY 이후에 처리합니다.

`Main.Stock`이 `SelectionUI/Stock`에 연결되어 있습니다. `ui/StockDisplay.cs`의 ResourceNames는 초기화할 자원 번호와 이름을 등록합니다. 이름은 화면에 표시하지 않으며, 목재 외 종류는 공통 아이콘과 작은 종류 번호로 구분합니다. 잘못된 형식·음수·범위를 벗어난 값은 무시합니다. 수량은 64비트 정수로 받습니다.

MAP 재동기화와 연결 종료 시 이전 값을 지웁니다. 등록된 자원은 0으로 돌아가므로 재접속 전체 목록에서 생략된 자원에 과거 수량이 남지 않습니다. 연결 종료 상태는 기존 SyncStatus로 표시합니다.

검증: `tests/StockChecks.tscn`에서 메시지 분기, 총량 교체, 중복·감소·0, 잘못된 메시지, 여러 종류, 재접속·연결 종료 초기화를 확인합니다.

인구수는 목재 옆에 사람 아이콘과 사용 / 최대 형식으로 표시합니다. 서버의 SUPPLY used limit 값을 그대로 반영하며, 생산 대기열도 사용 인구에 포함됩니다. 회관은 10, 완성된 합숙소는 5를 제공하고 서버 상한은 100입니다. 사용량이 한도 이상이면 붉게 표시하며 건물 파괴로 한도를 초과한 값도 그대로 표시합니다. MAP 재동기화·접속 종료 시 0 / 0으로 초기화하고 WORLD_READY 이전 메시지는 무시합니다.
