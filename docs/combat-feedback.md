# 사망 연출과 명령 대상 표시

클라이언트만 변경하며 서버 메시지 형식과 게임 판정은 그대로 사용합니다.

## 사망

`REMOVE`를 받으면 유닛을 관리자 목록/선택/클릭 판정에서 즉시 제외합니다. 화면 모델만 남겨 기사·궁수·일꾼 모두 같은 연출을 재생합니다.

- 0.45초 동안 바라보는 방향을 기준으로 옆으로 넘어집니다.
- 바닥에 0.15초 머물렀다가 0.45초 동안 흐려지며 사라집니다.
- 일꾼의 도끼질과 호흡은 사망 시작 때 정지합니다. 들고 있던 도끼나 통나무도 같이 넘어집니다.
- 사망 중 추가 POS/STATE/REMOVE는 이동하거나 연출을 재시작하지 않습니다.
- 맵 초기화는 진행 중인 사망 연출까지 즉시 정리합니다.

공통 연출은 `units/UnitDeathEffect.cs`, 게임 오브젝트 제외는 `UnitManager.HandleRemove`, 클릭 차단은 `Unit.BeginDeath`에서 처리합니다. 현재 REMOVE에는 제거 이유가 없으므로 접속 종료로 제거된 유닛도 같은 연출을 사용합니다. 타격과 사망 시점을 정밀하게 맞추는 서버 선딜 기능은 추가하지 않았습니다.

## 대상 원

`input/CommandTargetIndicator.cs`는 마지막으로 요청한 명령의 대상 한 곳을 표시합니다.

- 나무 우클릭/GATHER 요청: 노란 원.
- 적 우클릭 또는 A → 적 좌클릭/ATTACK 요청: 빨간 원.
- 원은 대상의 자식이므로 움직이는 적을 따라갑니다. 내 유닛의 초록 선택 원과 독립적입니다.
- 새 대상 명령, 이동 명령, 선택 변경, 대상 제거/나무 소진 시 이전 원을 지웁니다.

이는 클릭한 명령 대상에 대한 로컬 피드백입니다. 서버 승인 표시나 서버가 자동으로 다시 고른 모든 채집 대상을 표시하는 기능은 아닙니다.
