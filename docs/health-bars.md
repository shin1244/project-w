# 체력바

서버는 생성/접속 스냅샷에 `HP id current maximum`을 포함하고 틱 끝에는 마지막 방송 값과 달라진 체력만 보낸다. 한 틱의 여러 피해/회복은 최종값 한 번으로 합친다. 새 접속자에게 스냅샷을 보낼 때 기존 접속자의 변경 전송 캐시는 건드리지 않는다. 최대 체력 변경도 전송 대상이다.

클라이언트는 WORLD_READY 이후 HP를 받아 UnitManager/BuildingManager에서 ID로 찾아 갱신한다. 처음 HP를 받기 전에는 바를 숨긴다. 체력 0만으로 삭제하지 않고 서버 REMOVE 때 유닛 사망 연출과 함께 바를 숨긴다. 알 수 없는 ID와 잘못된 수치는 무시한다.

`ui/HealthBar.cs`를 유닛·건물이 공통으로 사용한다. 발밑에서 유닛 2.4, 회관 4.7 높이를 화면에 투영한다. 각 스크립트의 HealthBarHeight로 조정할 수 있다. 화면 크기는 유닛 52×7, 회관 76×7이며 줌과 회전에 관계없이 유지한다. 클릭을 가로채지 않고 맵 초기화/삭제 시 부모와 함께 정리된다. 초록/노랑/빨강은 진영이 아닌 남은 체력 비율을 나타낸다.

회관 초기 체력은 서버 `building.go`의 townHallMaxHP(임시 1000). 건물 공격/파괴 판정은 아직 추가하지 않았다. 유닛 체력은 기존 정의를 사용한다.
