# 아트 디렉션: 증기 시대 변경 도시

배경·건물·유닛·효과가 한 세계에 속해 보이도록 정한 기준입니다. 새 모델을 만들거나 기존 모델을 고칠 때 이 문서를 먼저 확인합니다. 기준과 다르게 만들 이유가 있으면 이 문서를 같은 PR에서 고칩니다.

## 한 줄 컨셉

**석탄과 증기로 돌아가는 1870~1890년대 변경 도시.** 벽돌과 철골로 지은 공장 도시가 숲과 유전을 차지하려고 싸운다. 마법은 없고, 신기해 보이는 것은 모두 기계와 압력으로 설명된다.

- 기준 시대: 빅토리아 시대 후기의 산업 혁명. 철도, 가스등, 증기 기관, 리벳으로 이은 철판, 전신, 초기 석유 시추.
- 과장 정도: 실제 역사보다 기계가 크고 많지만, 작동 원리는 눈으로 보여야 한다(톱니가 맞물리고, 피스톤이 밀고, 증기가 새어 나온다).
- 피할 것: 성곽 총안과 십자가 깃발 같은 중세 요소, 룬과 빛나는 수정 같은 마법 판타지, 네온과 전자 화면 같은 사이버펑크.

## 핵심 원칙

1. **작동이 보이는 기계.** 장식용 톱니를 붙이지 않는다. 톱니는 다른 톱니나 톱니 막대와 맞물리고, 굴뚝에는 연기가, 압력통에는 배관과 밸브가 이어진다. 움직이는 부품은 실제로 움직인다(포격차의 수평 톱니, 반동 복귀, 지지대 참고).
2. **재료로 말한다.** 철, 황동, 구리, 붉은 벽돌, 그을린 목재, 캔버스, 가죽 여섯 가지로 대부분을 만든다. 흰 석재와 파란 슬레이트는 쓰지 않는다.
3. **위에서 봐도 읽히는 실루엣.** RTS 카메라는 높이 비스듬히 내려다본다. 굴뚝, 크레인 팔, 탱크, 돔 같은 높은 요소로 건물 종류를 구분하고, 작은 디테일은 실루엣을 바꾸지 않는 선에서만 넣는다.
4. **팀색은 칠한 면에만.** 진영색은 천, 페인트칠한 철판, 깃발, 차양에만 쓴다. 금속과 벽돌은 원래 색을 유지한다(`visuals/TeamMaterials.cs` 규칙과 같다).
5. **디테일은 크기에 비례.** 화면에서 작은 것일수록 단순하고 굵게 만든다. 미니언은 병력보다 단순하지만 같은 재료와 색을 쓴다.

- 발광: 용광로·보일러 불빛(`#FF8A3D` 계열)과 가스등(`#FFD37A` 계열)만 쓴다. 청록·보라 마법 빛은 쓰지 않는다.

## 형태 언어

쓰는 것:
- 리벳으로 이은 철판, 볼트 체결 플랜지, 철골 트러스, 아치형 철제 창틀
- 굴뚝과 증기 배출구, 압력계, 밸브 핸들, 배관 다발
- 크레인 팔, 도르래와 와이어, 톱니와 톱니 막대
- 나무 상자, 석탄 더미, 기름통, 레일과 짐수레
- 가스등, 전신주, 함석 차양

쓰지 않는 것:
- 성곽 총안, 십자가·종교 문양, 반목조 오두막, 초가·슬레이트 지붕
- 룬 문양, 떠 있는 돌, 수정, 마법진
- 화면 장치, 네온, 매끈한 플라스틱 곡면

## 묶음별 기준

### 환경

- **지면:** 크림색 포석을 그을린 자갈길과 벽돌 포장으로 바꾼다. 라인 도로에는 철로 침목이나 짐수레 바퀴 자국을 넣어 길이 읽히게 한다. 건설 가능한 풀밭은 그대로 두되, 본진 바닥은 공장 부지처럼 다진 흙과 석탄 가루 색으로 맞춘다.
- **외벽:** 흰 석성 대신 붉은 벽돌 방벽에 철판 띠와 철골 버팀대를 댄다. 위에서 볼 때 두께와 높이는 지금과 같게 유지해 지형 가독성을 바꾸지 않는다.
- **숲:** 나무 숲은 유지한다(나무는 자원이고 공장 도시가 차지하려는 대상이다). 가장자리 일부를 벌목 흔적, 그루터기, 쌓인 통나무로 바꿔 산업이 숲을 먹어 들어가는 느낌을 준다.
- **유전:** 균열 암반에 기름 웅덩이와 그을음 얼룩을 더한다. 시추탑 주변에는 배관과 기름통을 둔다.
- **소품:** 가스등, 전신주, 석탄 더미, 버려진 짐수레를 라인 가장자리에 띄엄띄엄 둔다. 이동 충돌과 시야에는 영향을 주지 않는 장식만 쓴다.

### 건물

모든 건물은 붉은 벽돌 또는 철판 몸체 + 함석·철판 지붕 + 굴뚝이나 배관을 기본으로 한다. 크기와 점유 영역(`buildingDefs[...].Size`)은 서버가 정하므로 바꾸지 않는다.

| 건물 | 지금 | 목표 |
|---|---|---|
| 회관 | 종탑이 있는 반목조 회관 | 시계탑과 큰 굴뚝이 있는 벽돌 공장 본관. 티어가 오를수록 굴뚝과 증기 탱크가 늘어난다 |
| 요새 | 흰 석성 탑 | 리벳 철판 포대. 회전 포탑이나 증기 기관포를 얹은 벽돌 보루 |
| 망루 | 나무 망루와 종 | 철골 감시탑과 탐조등, 위에 소형 증기포 |
| 주택 | 반목조 2층집 | 벽돌 연립 주택. 지붕 위 굴뚝 여러 개 |
| 병영 | 반목조 막사 | 벽돌 병영과 훈련장 철책, 정문 위 진영색 차양 |
| 보급기지 | 차양 달린 오두막 | 하역장. 크레인 팔과 상자 더미, 레일 짐수레 |
| 대장간 | 오두막 + 화덕 | 증기 해머가 있는 주물 공장. 용광로 불빛 |
| 공방 | 오두막 + 보일러 | 철골 지붕의 조립 공장. 큰 미닫이 철문과 크레인 |
| 기술연구소 | 황동 돔 | 유지하되 벽을 벽돌로, 돔 옆에 전신 안테나와 배관 |
| 시추탑 | 목조 시추탑 | 유지. 배관과 기름통, 펌프 잭을 더한다 |

### 유닛

- **크기 기준:** 미니언 1.0 → RTS 병력 약 1.3 → 영웅 약 1.65 → 기계 유닛(차량) 그 이상. 크기는 [1티어 정규군 미리보기](images/tier-one-units.png) 기준을 따른다.
- **일꾼:** 작업복과 멜빵, 안전모, 등에 공구 가방. 기름을 나를 때는 금속 통을 든다.
- **미니언:** 스팀돌격병·공압사수를 단순화한 징집병. 같은 제복 색과 황동 포인트를 쓰되 부품 수를 줄인다. 치유 미니언은 의료 가방과 증기 분무기를 든다.
- **공성추:** 통나무 대신 바퀴 달린 철제 증기 충각. 앞쪽 철제 머리와 뒤쪽 보일러.
- **치유사:** 의무병 제복과 증기 분무기·약품 가방.

### 영웅

- **사령관:** 기준에 맞는다. 유지.
- **돌연변이 늑대:** 괴수는 유지하되 실험체로 설명한다. 몸에 박힌 압력관, 금속 턱 보강, 등의 약품 탱크. 붉은 생체 발광은 보일러 불빛 색으로 맞춘다.
- **룬 골렘:** 마법 수정 대신 **증기 골렘**으로 바꾼다. 리벳 철판 몸통, 가슴의 보일러 노심(용광로 불빛), 관절의 피스톤. 보호막 효과는 증기 장막이나 철판 방패로 다시 그린다.
- **레인저:** 지금은 공압사수 모델을 키운 임시 모델이다. 장거리 저격용 공압 소총과 망원 조준경, 긴 외투를 입은 고유 모델이 필요하다.

### 정글 몬스터

변경 도시 밖의 야생으로 설명한다. 늑대·멧돼지는 그을음과 기름에 오염된 짐승, 바위 괴물과 나무 괴물은 버려진 기계와 엉킨 나무(녹슨 보일러를 감싼 덩굴 등)로 다시 그린다. 마법 빛은 쓰지 않는다.

## 효과와 UI

- **증기:** 흰색~옅은 회색, 위로 퍼지며 사라진다. 지금 증기포격차의 전환 증기와 같은 방식이다.
- **불:** 주황~노랑. 화염기계 불꽃과 포구 화염이 기준이다.
- **그을음·먼지:** 어두운 회갈색. 착지, 포격, 건물 파괴에 쓴다.
- **마법 효과 대체:** 영웅 스킬도 증기 분출, 전기 아크(전신 시대 수준의 굵고 흰 불꽃), 압축 공기 충격파, 화약 폭발로 표현한다.
- **UI:** 지금의 어두운 남색 바탕 + 금색 테두리는 기준과 맞는다. 아이콘은 황동 판에 음각한 느낌으로 통일한다.

## 작업 순서 제안

1. **건물:** 가장 넓게 어긋나 있고 화면에서 차지하는 면적이 크다. 회관 → 생산 건물 → 요새·망루 순.
2. **지면과 외벽:** 건물과 같이 바뀌어야 대비가 어색하지 않다.
3. **미니언과 공성추:** 라인에서 항상 보이므로 영웅보다 먼저.
4. **룬 골렘, 돌연변이 늑대, 레인저 고유 모델.**
5. **정글 몬스터와 환경 소품.**

각 단계는 모델만 바꾸고 점유 영역, 충돌 크기, 선택 원, 체력바 높이는 유지한다. 바뀐 모델은 기존 미리보기 장면으로 캡처해 해당 문서 이미지를 갱신한다.

## 새 모델 점검표

- [ ] 재료 여섯 가지와 팔레트 안에서 만들었다.
- [ ] 진영색은 칠한 면(`team_cloth`, `banner`, `roof` 재질)에만 있고, 위에서 한두 곳 이상 보인다.
- [ ] 움직이는 부품은 실제로 움직이거나, 움직일 수 있는 구조로 보인다.
- [ ] 높은 카메라에서 실루엣만으로 종류를 구분할 수 있다.
- [ ] 중세(총안, 반목조, 십자가)나 마법(룬, 수정, 청록 빛) 요소가 없다.
- [ ] 점유 영역·충돌·선택 원·체력바 높이를 바꾸지 않았다.
- [ ] 미리보기 이미지를 갱신했다.
