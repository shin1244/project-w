# RTS 조작

드래그 박스에 몸통 중심이 들어온 내 유닛을 최대 64개 선택합니다. 일반 클릭·드래그는 이전 선택을 대체하며, 빈 박스는 선택을 해제합니다. Shift+클릭은 추가/제외, Shift+드래그는 새 유닛이 있으면 추가하고 박스 안이 전부 선택돼 있으면 제외합니다. 더블클릭은 화면 안의 같은 종류인 내 유닛을 선택하며, Shift+더블클릭은 기존 선택에 추가합니다. 드래그 중 Esc 또는 우클릭으로 취소할 수 있습니다.

Ctrl+1~9로 선택한 부대를 저장하고, 숫자로 다시 선택합니다. 같은 숫자를 빠르게 두 번 누르면 부대 중심으로 카메라를 옮깁니다. 미니맵 좌클릭·드래그는 카메라 이동, 우클릭은 선택 부대 이동이며 밝은 사각형으로 현재 카메라 범위를 표시합니다. 서버 변경 없이 기존 이동 명령을 사용합니다.

하단 미니맵과 명령 패널 사이에 높이 186px의 선택 상세정보를 표시합니다. 단일 선택은 이름·초상화·체력·행동 상태, 다중 선택은 개별 초상화·체력바를 보여줍니다. 초상화 클릭은 단일 선택, Shift+클릭은 제외, Ctrl+클릭은 같은 종류만 선택합니다. 많은 유닛은 페이지 버튼으로 확인하며 전체 선택은 유지됩니다.

선택 후 적 유닛·건물을 우클릭하거나 A를 누르고 적을 좌클릭하면 `ATTACK 대상ID 내유닛ID...`를 보냅니다. A를 누르면 십자 커서와 노란 공격 사거리 원이 표시되고, 한 번 클릭하거나 Esc를 누르면 종료됩니다. 영웅 모드는 내 영웅, 지휘관 모드는 선택한 내 유닛들의 사거리를 표시합니다. 원은 서버의 사거리와 유닛 충돌 반경을 사용하며, 적의 몸체가 원에 닿으면 사거리 안입니다. A 이후 빈 땅을 좌클릭하면 공격 이동(`ATTACK_MOVE`), 같은 진영 유닛·건물은 명령 없이 종료합니다. 땅 우클릭은 일반 이동입니다. 적 판정은 서버가 보낸 진영으로 구분하며 공격 판정은 서버에서 처리합니다.

건물을 좌클릭하면 유닛 선택이 해제되고 건물 체력바를 확인할 수 있습니다. HQ 2개와 요새 8개는 서버 배치대로 표시하며, 완성된 요새와 감시탑의 조준·발사·피해·파괴는 서버 STATE/HP/REMOVE에 맞춰 반영합니다.

## 전장의 안개

전장의 안개는 같은 진영 유닛·미니언·건물의 시야를 공유합니다. 나무·벽은 이동과 시야를 막고, 건물은 이동만 막습니다. 시야와 공격 사거리는 몸 가장자리 사이의 거리로 계산합니다. 건물 위치는 처음부터 알려져 있지만 적 건물의 조회·공격에는 현재 아군 시야가 필요합니다. 외벽이 시야에 들어오면 건물 모델 전체를 밝히고 주변 땅의 안개는 유지합니다. 적 유닛은 시야 밖에서 HIDE로 사라지고 다시 보이면 최신 상태로 등장합니다. 최신 서버와 클라이언트를 함께 사용하세요.

## 정지·홀드와 카메라

공격 버튼/A는 기존 공격 대상 지정, 정지 버튼/S는 현재 작업 중단 후 주변 경계, 홀드 버튼/D는 위치 사수입니다. 정지는 주변 적을 추격하고 돌아오며, 홀드는 사거리 안의 적만 공격하고 자리를 떠나지 않습니다. 작업 중단 시 운반 자원과 공사 부지는 유지됩니다. 클라이언트와 서버를 함께 갱신해야 합니다.

맵 카메라는 마우스를 화면 가장자리에 가져가거나 가운데 버튼 드래그·미니맵으로 이동합니다. 키보드(문자·방향키)로는 움직이지 않습니다. 휠로 확대/축소, Home으로 전체 보기이며, **Space는 영웅 모드에서 내 영웅 위치, RTS 지휘관 모드에서 내 진영 본진으로 이동**합니다. Space는 현재 줌과 선택을 유지합니다. 가장자리 이동은 창 밖·포커스 해제·마우스 드래그 중에는 멈춥니다. 문자 키는 명령과 스킬에 씁니다(A 공격, S 정지, D 홀드, 영웅 Q/W/E/R).

## 건설

내 일꾼을 선택하고 **Z / 넘패드 1 위치의 1티어 버튼**을 누르면 건설 메뉴로 들어갑니다. Q는 브랜치, W는 숙소, E는 시추탑, A는 인력 사무소, S는 조병창, D는 감시탑입니다. 메뉴가 열려 있는 동안 해당 키는 건설 메뉴에 사용합니다. [명령 패널](command-panel.md)을 참고하세요.

건물을 고르면 반투명 미리보기가 나타나고, 지면을 좌클릭하면 `BUILD 건물타입 x z 일꾼ID`를 요청합니다. 회색 도로·벽·나무·건물·알려진 유닛과 겹치거나 맵 밖이면 빨간색과 사유를 표시하고 전송하지 않습니다. 일반 건물은 초록색 빈 부지와 벌목이 끝난 자리에 건설할 수 있으며, 시추탑만 등록된 유전 중심에 건설합니다. [도로·건설 부지·초기 숲 배치](map.md)를 참고하세요. 우클릭·Esc로 취소합니다. 타입 순서는 **HQ 0, 요새 1, 브랜치 2, 숙소 3, 인력 사무소 4, 조병창 5, 감시탑 6, 시추탑 7**입니다. 브랜치는 `Store.tscn`/`store`, 조병창은 `Forge.tscn`/`forge`로 구분합니다. [건설 배치](../buildings/README.md#건설-배치)를 참고하세요.

서버가 공사를 시작하면 건물 크기에 맞춘 공통 테두리와 글자 없는 중앙 팻말을 표시합니다. 진행률은 선택 상세정보 창에 표시하고, `CONSTRUCTION 건물ID 진행률`이 100이 되면 완성 모델로 바꿉니다. 내 일꾼을 선택하고 아군 공사 부지를 우클릭하면 한 명에게 `CONSTRUCT 건물ID 일꾼ID`를 보내 이어 짓습니다. 다른 건설자가 있는지는 서버가 판정하고 `ERR 이미 짓는 중`을 알립니다. 공사 중 건물도 파괴 시 즉시 제거합니다.

HQ는 5×5, 석조 요새(`Fortress.tscn`, 타입 1)는 4×4, 목조 감시탑(`Tower.tscn`, 타입 6)은 3×3입니다. 요새는 시작 건물이고 감시탑은 목재 200·30초로 건설합니다. 기존 모델을 확대해 서버 점유 크기에 맞췄으며, 게임 속 건물의 정면은 플레이어의 카메라 방향을 향합니다. 서버 회전값은 입구 방향에만 적용하고 충돌·배치·공사 테두리는 서버와 같은 축 정렬 영역을 사용합니다. `previews/Buildings.tscn`에서 HQ·요새·감시탑을 같은 배율로 비교할 수 있습니다.

배치 미리보기는 시작 때 읽어 둔 투명 이미지를 재사용합니다. 버튼 클릭 시 모델을 생성하지 않고 위치·크기·색만 갱신합니다. 공사 부지는 공통 3D 표시를 쓰고, 완공 후에는 각 건물의 3D 모델을 표시합니다.

## 채집과 반납

내 일꾼을 선택하고 완성된 아군 시추탑을 우클릭하면 `GATHER 시추탑ID 일꾼ID...`를 보냅니다. 일꾼은 기름을 채집해 완성된 아군 HQ·브랜치에 반납한 뒤 같은 시추탑으로 돌아갑니다. 빈 유전에서는 채집할 수 없고, 공사 중 시추탑 우클릭은 이어 짓기로 처리합니다.

스타크래프트의 가스처럼 일꾼은 시추탑 안으로 들어가 기름을 캐고 나옵니다. 서버가 `STATE id INSIDE 0 시추탑ID ...`를 보내면 그 일꾼의 모델을 숨기고 선택·조회에서 뺍니다. 다른 상태가 오면 다시 보입니다. 한 번에 한 명만 들어가므로 나머지는 시추탑 옆에서 차례를 기다립니다.

자원을 든 일꾼으로 완성된 아군 HQ·브랜치를 우클릭하면 `RETURN 건물ID 일꾼ID...`로 반납을 요청합니다. 진행 중인 채집 명령이 있었다면 반납 후 재개합니다. 목재와 기름 사이에서 채집 대상을 바꾸면 기존 짐을 먼저 반납하며, 보유량은 반납이 끝난 뒤에만 증가합니다. 시추탑이 파괴되면 이미 캔 기름을 반납한 뒤 멈춥니다. 이동 중 가까운 브랜치가 완성되면 자동 채집의 반납 경로를 갱신합니다.

기름을 운반하는 일꾼은 목제 기름통을 들고, 상단 자원창에는 기름 아이콘과 보유량이 표시됩니다. `previews/OilGathering.tscn`은 실제 모델과 HUD에 예시 메시지를 적용한 외형 미리보기이며, 채집 시뮬레이션은 실행하지 않습니다.

## 미리보기와 나무

서버 없이 외형을 확인하려면 `previews/Units.tscn`, `previews/Trees.tscn`, `previews/Arena.tscn`, `previews/Forest.tscn`, `previews/TownHall.tscn`을 열고 F6으로 실행합니다. 숙소·브랜치·인력 사무소·조병창은 `previews/ProductionBuildings.tscn`에서 함께 보고 회전·확대할 수 있습니다. 브랜치는 4×4, 숙소는 3×3, 조병창은 인력 사무소와 같은 4×3이며 개별 미리보기는 `previews/Store.tscn`, `previews/Forge.tscn`입니다. 공방은 4×4이며 `previews/Workshop.tscn`에서 확인합니다. 건물의 비용·공사·완공과 인구수, HQ·인력 사무소의 생산 대기열·취소·랠리를 서버와 동기화합니다. 브랜치는 완공되면 같은 팀 일꾼의 목재·기름 반납 거점으로 사용됩니다. [건물별 영어 이름](../buildings/README.md#영어-이름-추천)도 정리했습니다.

나무는 `resources/trees/Tree.tscn`을 Oak/Pine/Birch 씬이 상속합니다. 자원 ID와 선택 표시(`ResourceNode.cs`), 클릭 영역(물리 레이어 3)은 공통이며 `Visual` 아래 외형만 다릅니다. `VisualVariant`는 외형 번호로, 자원 종류나 채집 능력치를 구분하지 않습니다. 나무는 맵 파일에서 생성하며 서버는 남은 자원량과 제거 변경분만 보냅니다. 유닛 선택 후 나무를 우클릭하면 `GATHER 자원ID 내유닛ID...`를 보냅니다. 실제 채집 가능 여부는 서버가 검사합니다.
