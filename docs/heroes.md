# 영웅 화면과 조작

> 게임 규칙과 수치의 기준은 서버 저장소 `project-w-server/docs/`입니다. 이 문서는 클라이언트 화면과 조작을 설명합니다.

## 공통

인게임 영웅 본체는 두 팀 모두 같은 고유 색상을 사용합니다. 시야 안의 살아 있는 영웅은 선택하지 않아도 발밑 원이 보이며, 아군은 파란색·적군은 붉은색으로 구분합니다. 관전자는 1팀이 파란색, 2팀이 붉은색입니다. 선택한 영웅은 같은 원의 두께로 강조하며, 사망하거나 시야에서 사라지면 원도 함께 사라집니다.

`WELCOME id 편 COMMANDER`는 RTS 정보창, `WELCOME id 편 HERO 영웅종류`는 가운데 하단의 AOS 스킬 패널을 표시합니다. 늑대는 Q키나 Q 버튼을 누른 뒤 적 유닛을 클릭하면 물어뜯기를 사용합니다. 대상 지정 중에는 늑대 주변에 사거리 원을 표시합니다. Esc·우클릭으로 대상 지정을 취소하며, 스킬마다 서버 기준 남은 재사용 시간을 표시합니다. 패시브는 항상 적용되고, W는 다음 일반 공격 또는 Q 명중 시 흡혈, E는 주변 지속 피해, R은 아군 미니언·용병을 먹는 포식입니다. 맵·미니맵은 공유하고, AOS의 오른쪽 명령창은 208×160 간단 정보 패널로 바뀝니다. 기본은 내 영웅이며 다른 유닛을 클릭하면 그 유닛의 체력과 능력치를 표시합니다. 내 영웅의 레벨·경험치바는 서버의 EXP 수신값으로 갱신합니다.

AOS에서는 내 영웅이 생성되면 자동으로 조종 대상으로 고정됩니다. 별도 선택 없이 우클릭·미니맵 우클릭으로 이동하고 적 우클릭으로 공격합니다. A/S/D도 같은 영웅을 조종하며 빈 곳·다른 유닛·건물 클릭이나 드래그로 해제되지 않습니다. 다른 유닛을 좌클릭하면 오른쪽에 초상화·이름·체력·행동·공격력·사거리만 표시하며 명령 대상은 바뀌지 않습니다. 조회 대상이 죽거나 시야에서 사라지면 정보를 비웁니다. 내 영웅의 사망·시야 이탈·소유권 상실 시 명령을 멈추고, 다시 생성되면 자동으로 연결합니다. RTS는 기존 수동 선택과 명령창을 유지합니다.

경기 시작 시 내 영웅 또는 본진을 가까이 보여주며, 상단 중앙에는 경기 경과 시간(`MM:SS`), 양옆에는 팀 레벨을 표시합니다. 내 팀은 왼쪽, 상대 팀은 오른쪽이며 관전자는 1팀·2팀 순서입니다. 마석 상태는 바로 아래 작은 한 줄로 표시하고 상시 조작 안내와 승리 목표 설명은 생략합니다. 영웅 모드에서는 지휘관 전용 자원·인구 UI를 숨깁니다. 미니맵의 내 영웅은 밝은 큰 표식으로 구분합니다. 다친 유닛은 선택하지 않아도 체력바를 표시하지만, 안개로 숨겨진 유닛의 정보는 표시하지 않습니다.

마나바는 서버의 `MANA id 현재 최대`를 수신한 영웅에 표시합니다. 스킬 아이콘의 비용은 `MANA_COST 영웅종류 슬롯 비용`을 따르며, 받은 마나가 부족하면 해당 버튼과 단축키 요청을 막습니다. 소비·재생·실제 시전 성공은 서버가 결정하고, 클라이언트는 마나를 미리 차감하거나 시간만으로 회복시키지 않습니다. 사망·시야 이탈·새 영웅 연결 시 이전 마나를 지우고 새 스냅샷을 기다립니다. 역할 변경·맵 재동기화·접속 종료 때도 이전 상태를 남기지 않습니다. 이 연동은 해당 메시지를 보내는 서버와 함께 적용해야 합니다.

스킬 사용법·강화 설명은 마우스를 올리면 바로 뜨는 툴팁으로 확인합니다. 평상시에는 안내 문장을 표시하지 않고, 강화 포인트가 있을 때만 포인트 수와 `+` 버튼을 표시합니다. 기절·대상 지정·부활 대기처럼 현재 판단에 필요한 상태 안내는 유지합니다. 조회 창의 공격력·공격 속도·사거리·시야·이동 속도는 아이콘과 수치로 표시하며, 뜻과 단위는 같은 방식의 툴팁으로 확인합니다.

사망 시 `RESPAWN 부활틱`과 서버 `TICK`으로 남은 초를 표시합니다. 부활 예정 시간이 지나도 새 영웅이 생성되지 않았다면 부활 위치 확보 중으로 안내하며, 실제 UNIT 수신 후 정상 상태로 돌아갑니다. 스킬 대상 지정·기절·침묵·체력 위험도 영웅 패널에 안내합니다.

## 늑대 (200)

첫 영웅(200)은 사족보행하는 돌연변이 늑대로, 연구소에서 달아난 연금술 실험체입니다. 오른쪽 옆구리의 작은 팔 하나, 긴 주둥이·송곳니·날카로운 갈기와 군데군데 드러난 뼈에 더해, 등에 묶은 안장판 위의 유리 약품 실린더 두 개(청록 약품)와 거기서 목덜미·작은 팔로 들어가는 구리관, 끊어진 사슬과 번호표가 달린 철 목줄, 왼쪽 귀의 황동 번호표, 갈비 둘레의 봉합 스테이플과 꿰맨 자국, 황동 피스톤 의족으로 바꾼 왼쪽 앞다리로 구분합니다. 별도의 모델·초상화·보행·물기 연출을 사용합니다. 서버의 UNIT/POS/STATE/HP/STATS와 기존 타입 번호는 그대로 사용합니다. AOS 체력바와 마나바는 내 영웅의 서버 수신값을 표시하며, 아직 마나를 받지 않았다면 마나바를 숨깁니다.

영웅 모드 왼쪽 위의 팀원 창(`ui/TeamFrame.cs`)은 같은 편 다른 영웅마다 초상화·이름·체력·마나를 한 줄씩 보여 줍니다. 아군은 늘 시야에 있으므로 서버의 `UNIT`·`HP`·`MANA`로 갱신하고, 죽으면(`REMOVE`) 초상화를 어둡게 하고 `TEAM_RESPAWN 플레이어ID 부활틱`으로 부활까지 남은 초를 표시합니다. 다시 `UNIT`이 오면 새 영웅으로 바꿉니다. 적 영웅, 내 영웅, 팀원의 일반 유닛은 넣지 않고, 팀원이 없으면 창을 숨깁니다. 학습 영웅 AI도 이 창에 보이는 만큼만 팀원 정보를 씁니다(카메라 밖 적은 위치만 압니다).

외형은 `previews/MutantWolf.tscn`을 F6으로 열어 세 시점에서 확인합니다. Space는 걷기, A는 물기, Q는 돌진 자세, R은 회전, T는 진영색 전환입니다. [영웅 미리보기](images/mutant-wolf.png).

물기에는 준비·반동 동작을, W에는 송곳니 발광을, E에는 안개·파문을, R에는 몸으로 모이는 입자를 표시합니다. 서버가 승인한 스킬과 효과 상태로만 연출하며 유닛 위치나 피해를 예측하지 않습니다.

늑대 **W · 피의 송곳니**는 다음 일반 공격 또는 Q 명중으로 실제 깎은 체력의 일부를 회복합니다. 명중으로 W를 소모하면 재사용 시간이 시작됩니다. Q가 빗나가거나 중단되면 W는 유지되며, E는 W를 소모하지 않습니다. 보호막 피해·초과 피해는 회복에 포함하지 않고 최대 체력을 넘지 않습니다. **E · 피의 안개**는 늑대를 따라다니는 영역에서 주기적으로 피해를 줍니다. 흡혈량·타격 횟수·재사용 시간은 서버 `hero_wolf.go`의 정의와 스킬 강화 상태를 따릅니다. W/E 모두 키나 버튼을 누르면 바로 발동합니다. 분홍 고리는 W 대기, 붉은 영역은 E 활성 상태이며 하단에도 남은 효과를 표시합니다. W/E 상태는 서버 `WOLF` 메시지로 동기화되어 안개 재등장 시 복원되고 사망·부활 시 초기화됩니다. 늑대 W도 카메라 이동과 겹치지 않습니다.

## 룬 골렘 (201)

두 번째 영웅(201)은 **룬 골렘**입니다. 로비의 영웅 선택에서 고르면 영웅 역할로 배정될 때 적용됩니다. 옛 룬석을 리벳 철판과 황동 띠로 감싼 마법 공학 병기입니다. 가슴의 황동 포트홀과 금 창살 안에 청록 룬 결정 노심이 있고, 구리관이 노심에서 어깨를 넘어 등의 구리 보일러로 이어지며, 보일러 위 굴뚝 두 개에서 연기가 오르고 뒤쪽 화실 창살에는 불빛이 보입니다. 각진 철판 어깨 갑옷, 머리 대신 달린 가스등(위로 벌어진 유리창 속 등심이 노랗게 빛남), 팔·다리 뒤의 피스톤, 철띠로 조인 룬석 주먹으로 구분하며, 관절 보행과 주먹 공격, 보호막·충격파 효과를 사용합니다. 패시브 돌가죽은 받는 피해를 줄이며 패시브 강화에 따라 효과가 달라집니다.

좌우 주먹 타격, 내려찍기 준비·반동, 돌 파편·먼지, 떠 있는 보호막 조각과 회전하는 룬 문양으로 스킬을 구분합니다. 파편은 짧게 사라지는 시각 효과이며 지형·충돌에는 영향을 주지 않습니다.

| 키 | 기술 | 효과 |
| --- | --- | --- |
| Q | 내려찍기 | 주변 적에게 피해와 둔화. **R 강화:** 범위와 피해가 커지며 기본 둔화는 적용하지 않음 |
| W | 돌갑옷 | 최대 체력에 비례한 보호막. **R 강화:** 보호막량 증가 |
| E | 바위 돌진 | 적 클릭 후 돌진하여 피해와 기절. 장애물에 막힘. **R 강화:** 기절 시간 증가 |
| R | 룬 각성 | 다음에 성공적으로 사용하는 Q/W/E를 룬 강화. 사용하거나 사망할 때까지 유지되며 중첩되지 않음. 궁극기 강화로 적용 횟수가 늘어남 |

Q의 기절은 스킬 포인트로 Q를 4차 강화했을 때 일반·룬 강화 시전에 추가됩니다. R만으로는 Q에 기절이 생기지 않습니다. 피해·범위·지속 시간·재사용 시간은 서버 `hero_golem.go`, 스킬 강화는 `hero_progression.go`, 패시브 강화는 `hero_passive.go`의 정의를 따릅니다.

Q/W/R은 누르면 바로 사용합니다. R→Q는 넓은 범위의 피해, R→W는 생존, R→E는 단일 대상 기절에 투자하는 선택입니다. R 자체는 공격하지 않습니다. 금색 룬 고리와 하단 상태·툴팁이 강화 대기를 표시하며, 일반 공격·대상 선택 취소·시전 거절·E 접근 이동으로는 소모되지 않습니다. 준비 상태는 `GOLEM id 강화대기(0|1)`, 강화 시전은 `SKILL 시전자 슬롯 [대상ID] EMPOWERED`로 동기화합니다. 골렘의 Q/W는 스킬에 사용하며 카메라는 화면 가장자리·가운데 버튼 드래그·미니맵으로 움직입니다. `previews/RuneGolem.tscn`을 F6으로 실행하면 서버 없이 모델과 스킬 연출을 볼 수 있습니다(Space 걷기, A 주먹, Q/W/E 기술, R 다음 기술 강화, Y 회전, T 진영색). [룬 골렘 미리보기](images/rune-golem.png). 서버와 클라이언트를 함께 갱신해야 선택과 스킬이 적용됩니다.

## 사령관 (202)

사령관(202)은 귀족 장교입니다. 군복·견장·훈장·장교모자, 곡도·권총과 양면 문양 깃발에 더해, 권총을 쥔 왼팔 전체가 금장 황동 의수(톱니 팔꿈치·피스톤·관절 손가락)이고 등 오른쪽의 구리 압력통이 호스로 의수에 증기를 보냅니다. 오른쪽 눈의 금테 단안경, 오른쪽 견장에서 가슴으로 늘어진 금줄, 훈장 하나와 깃 금줄이 늘었고, 장화 앞코와 옷자락 끝에는 잿가루가 앉았습니다. 이동할 때 옷자락과 깃발이 움직입니다. 일반 공격은 곡도 타격, Q는 조준·총구 섬광·연기·탄도, W는 보호막, E는 전진 화살표, R은 지휘 링으로 표현합니다. Q의 조준은 승인된 `SKILL` 메시지의 현재 보이는 대상만 사용하며, 숨겨지거나 제거된 대상을 계속 추적하지 않습니다. E/R은 `MARSHAL`의 종료 틱과 `TICK`으로 만료됩니다.

I로 상점을 열고 B로 귀환합니다. 필드에서 구매한 아이템은 상자로 배달되며 내 영웅으로 상자를 우클릭해 줍거나, 지휘관이 자신의 일꾼을 선택한 뒤 상자를 우클릭해 배달시킬 수 있습니다. 가격·업그레이드 조건·실제 장착과 효과는 서버가 결정합니다.

영웅이 상자를 받으면 상자가 일꾼 머리 위나 바닥에서 영웅 등 위로 날아와 뚜껑이 열리고, 가스등 빛 반짝임이 솟고 발밑 고리가 좁혀진 뒤 영웅 안으로 사라집니다(`events/ItemCrateHandoff.cs`). `ITEM_CRATE_REMOVE`에는 사라진 이유가 없어서, 상자 주인의 영웅이 상자의 마지막 위치에서 `ItemCrateHandoff.ReceiveRadius` 안에 있을 때만 받은 것으로 보고 보여 줍니다. 판매·재구매로 지워진 상자처럼 영웅이 멀리 있으면 전처럼 그냥 사라집니다. 상자는 아군과 관전자에게만 보이므로 이 효과도 같습니다.

## 레인저 (203)

레인저(203)는 원거리 영웅입니다. 모델은 궁수 용병(`units/models/ArcherRig.tscn`)과 같은 활 든 병사를 1.3배로 키워 쓰고, 애니메이션도 궁수의 `ArcherAnimation`을 그대로 씁니다. 선택 초상화와 팀원 창 초상화도 궁수 그림을 씁니다. 스킬 전용 연출은 아직 없고, 스킬 아이콘(`ui/icons/ranger-*.svg`)과 설명(`SkillDescriptions`)만 추가했습니다. 데모에서는 서버의 선택 가능 영웅 목록(`matchspec.Heroes`)과 로비 영웅 선택에서 빠져 있어 경기에 나오지 않습니다. 장면·아이콘·설명은 남아 있어 서버 목록과 로비 선택지에 다시 넣으면 돌아옵니다.

## 디자인 미리보기

`res://previews/CompactHud.tscn`은 실제 HUD에 모의 서버 메시지를 넣어 팀 레벨·경기 시간·마나·스킬 비용·능력치 아이콘을 확인하는 장면입니다. 양쪽에 같은 영웅 세 종류를 배치해 공통 본체 색상과 발밑 팀 원도 비교합니다. 서버 접속이나 실제 경기 캡처가 아닙니다. 렌더 모드에서 `-- --capture`를 넘기면 `.godot/compact-hud.png`를 저장합니다.

![간결한 HUD 미리보기 — 모의 서버 메시지](images/compact-hud.png)

`previews/HeroVisuals.tscn`을 F6으로 실행하면 늑대·골렘·사령관 세 영웅의 모델·스킬 효과를 함께 확인할 수 있습니다. 레인저는 이 미리보기가 레인저 모델을 지원할 때까지 빠져 있습니다. Space 걷기, A 일반 공격, Q/W/E/R 스킬, T 진영색 전환을 지원합니다. 이 장면의 체력·보호막·효과 시간은 연출을 보기 위한 모의 값입니다.
