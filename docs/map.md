# 대칭 지형 프로토타입

참고 이미지의 좌우 본진, 상·하단 두 공격로, 중앙 우회 공간을 기반으로 만든 지형입니다. 건물과 장식은 없으며 게임에서는 JSON의 나무도 함께 생성합니다.

## 열기

- `game/Main.tscn`: 게임 장면. Ground의 MapWorld가 JSON에서 지형과 나무를 생성하며 유닛은 서버가 보낸 좌표에 생성됩니다.
- `previews/Forest.tscn`: 서버 없이 실제 맵과 나무를 함께 보는 장면. F6으로 실행합니다.
- `previews/Arena.tscn`: 지형만 보는 장면. Godot에서 열고 F6으로 실행합니다.
- `maps/SymmetricArena.tscn`: 편집용 미리보기 캐시입니다. 실제 게임에서는 JSON으로 새로 생성합니다.

휠로 확대/축소, W/S·Q/D·방향키 또는 마우스 가운데 버튼 드래그로 이동, Home으로 전체 보기로 돌아갑니다.

## 배치 기준

- 좌우 축: X, 위아래 축: Z, 높이: Y.
- 본진 중심: (-65, 0, 0), (65, 0, 0).
- 격자 데이터는 `maps/test.json`입니다. 원점은 (-84, -46), 한 칸은 1 × 1, 전체 배열은 168 × 92칸입니다. 외곽 빈 공간을 포함한 크기입니다.
- 공격로 중심선 기준 폭: 8 단위. 중심선 길이는 각각 약 155.75 단위입니다.
- X=0과 Z=0 기준으로 높이, 외곽, 길·공터, 삼각형 분할이 대칭입니다. 표면의 미세한 풀·흙 무늬와 조명에 따른 명암은 위치마다 다릅니다.
- 모든 지면은 Y=0인 평지입니다. 공격로와 내부 구역은 색으로만 구분하며 언덕은 없습니다. 외곽 옆면만 Y=-4.5까지 내려갑니다.
- `LayoutGuides`에 본진 Marker3D와 상·하단 Path3D를 제공합니다. 표시는 편집기용이며 게임 화면에는 보이지 않습니다.

## 범위

지형 표면의 정적 충돌을 포함합니다. 현재 Unit.cs는 서버 좌표로 위치를 직접 바꾸므로 클라이언트 지형 충돌로 이동이 제한되지는 않습니다. 이동 가능 여부는 서버의 격자로 판정합니다. 공격로 Path3D는 경로 참고 자료이며 미니언 이동 로직은 없습니다.

JSON에서 `#`은 지면이 없는 칸, `.`은 지면, `T`는 나무 점유 영역의 시작 칸입니다. treeSize=2이면 그 칸부터 +X/+Z 방향의 2×2칸을 나무 한 그루가 차지합니다. 나머지 세 칸은 JSON에서 `.`이지만 서버에서는 함께 차단됩니다. 클라이언트는 `T` 아래에도 평지를 생성하며 나무의 이동 차단은 서버가 처리합니다. 길·양쪽 본진·중앙 공터를 제외한 지면을 나무 1,360그루를 2×2칸 간격으로 배치했습니다. 모델 크기는 그대로이며, 네 칸 모두 숲에 들어가는 위치만 사용합니다. 지형과 나무 점유 영역은 양 축 대칭입니다. 나무의 차단 칸이 길에 걸치지 않도록 여유를 둡니다. 나무는 로컬에서 만들고 서버의 변경분만 적용합니다. 자세한 내용은 [맵 동기화](map-sync.md)를 참고하세요.

## 지형 수정 및 재생성

외곽은 `maps/test.json`의 rows를 수정합니다. 행은 작은 Z부터, 열은 작은 X부터 시작합니다. 외곽 대칭을 유지하려면 반대편 칸도 함께 수정합니다. 공격로·샛길 경로는 `maps/TerrainBuilder.gd`의 TOP_LANE, TRAIL_SEGMENTS, LANE_WIDTH로 조절합니다.

지면 재질은 `maps/materials/Ground.gdshader`에서 그립니다. 길과 원형 공터의 경계는 꼭짓점 색 대신 픽셀마다 계산하므로 확대해도 삼각형이나 계단 모양이 드러나지 않습니다. 지도 좌표를 기준으로 풀, 흙, 잔돌, 원형 돌 테두리를 표현하며 작은 무늬는 축소 시 약해지게 해 반짝임을 줄입니다. 지면에 실제 높이를 추가하지 않고 조명에만 미세한 요철을 적용합니다.

색상은 셰이더의 grass_dark/light, dirt_dark/light, stone_color로, 표면 요철 강도는 bump_strength로 조절합니다. 재질 수정은 맵 JSON과 서버 해시·충돌에 영향을 주지 않습니다. 셰이더 좌표·노멀 기준은 [Godot 공간 셰이더 문서](https://docs.godotengine.org/en/4.7/tutorials/shaders/shader_reference/spatial_shader.html)를 참고하세요.

```text
Godot --headless --path . --script tools/build_arena.gd
```

게임은 JSON 변경을 다음 실행 때 자동 반영합니다. 위 명령은 편집용 미리보기 캐시를 갱신할 때만 필요합니다. 명령은 프로젝트 루트에서 실행하고 Godot 대신 설치된 실행 파일 경로를 사용합니다. maps/SymmetricArena.tscn과 maps/resources/의 세 .res 리소스를 덮어씁니다. 재생성 후 편집기에서 장면을 다시 불러오세요. 손으로 추가한 노드는 별도 상위 장면에 두면 유지할 수 있습니다.

동일한 test.json을 Go 서버의 maps/test.json에도 복사하고 서버를 재시작해야 양쪽 외곽이 일치합니다. 파일 복사는 자동화되어 있지 않습니다.

`tests/check_arena.gd`는 지형의 평탄도와 대칭, JSON 각 칸의 지면 유무 및 공격로 충돌을 검사합니다.

숲 배치를 다시 채우려면 `Godot --headless --path . --script tools/plant_forest.gd`를 실행합니다. 현재 지면의 나무 배치를 길 모양에 맞춰 다시 쓰므로 수동 배치도 대체됩니다. 실행 후 서버에 같은 JSON을 복사하세요.
