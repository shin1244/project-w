# 대칭 지형 프로토타입

참고 이미지의 좌우 본진, 상·하단 두 공격로, 중앙 우회 공간을 기반으로 만든 지형입니다. 건물, 나무, 장식은 포함하지 않습니다.

## 열기

- `game/Main.tscn`: 게임 장면. Ground에 지형을 연결했으며 유닛은 서버가 보낸 좌표에 생성됩니다.
- `previews/Arena.tscn`: 지형만 보는 장면. Godot에서 열고 F6으로 실행합니다.
- `maps/SymmetricArena.tscn`: 카메라와 조명을 제외한 재사용 지형 장면입니다.

휠로 확대/축소, WASD/방향키 또는 마우스 가운데 버튼 드래그로 이동, Home으로 전체 보기로 돌아갑니다.

## 배치 기준

- 좌우 축: X, 위아래 축: Z, 높이: Y.
- 본진 중심: (-65, 0, 0), (65, 0, 0).
- 전체 지형은 약 164 × 88 단위이며 굴곡진 외곽에 따라 조금 달라집니다.
- 공격로 중심선 기준 폭: 8 단위. 중심선 길이는 각각 약 155.75 단위입니다.
- X=0과 Z=0 기준으로 높이, 외곽, 지면 색, 삼각형 분할이 대칭입니다. 방향광 때문에 보이는 명암은 다를 수 있습니다.
- 공격로·본진·중앙 길은 Y=0, 내부 언덕은 최대 약 3.4, 외곽은 절벽 형태입니다.
- `LayoutGuides`에 본진 Marker3D와 상·하단 Path3D를 제공합니다. 표시는 편집기용이며 게임 화면에는 보이지 않습니다.

## 범위

지형 표면의 정적 충돌을 포함합니다. 현재 Unit.cs는 위치를 직접 바꾸므로 이 충돌로 이동이 제한되지는 않습니다. 경로 탐색, 이동 가능 구역, 지형 높이에 맞춘 유닛 배치는 아직 연결하지 않았습니다. 공격로 Path3D도 경로 참고 자료이며 미니언 이동 로직은 없습니다.

중앙 공간은 이후 자원 구역과 벌목 샛길을 배치할 자리입니다. 자원·벌목 시스템은 포함하지 않습니다.

## 지형 수정 및 재생성

`tools/build_arena.gd`의 TOP_LANE, LANE_WIDTH, mound 배치와 height_at 함수를 조절합니다. 좌표의 절댓값을 사용해 한쪽 수정을 반대쪽에도 적용합니다.

```text
Godot --headless --path . --script tools/build_arena.gd
```

명령은 프로젝트 루트에서 실행하고 Godot 대신 설치된 실행 파일 경로를 사용합니다. 생성 시 대칭과 공격로 길이를 검사하며, maps/SymmetricArena.tscn과 maps/resources/의 세 .res 리소스를 덮어씁니다. 재생성 후 편집기에서 장면을 다시 불러오세요. 손으로 추가한 노드는 별도 상위 장면에 두면 유지할 수 있습니다.
