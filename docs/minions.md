# 서버 미니언 동기화

현재 서버 메시지 형식은 다음과 같습니다. 이전의 진영 없는 WELCOME/UNIT 형식은 사용하지 않습니다.

```text
WELCOME 플레이어ID 진영 COMMANDER
WELCOME 플레이어ID 진영 HERO 영웅종류
UNIT 타입 유닛ID 소유자ID X Z 진영
WELCOME 7 1 COMMANDER
UNIT 0 15459 7 -60.00 0.00 1
UNIT 100 15464 0 -60.00 -6.00 1
UNIT 101 15480 0 60.00 -6.00 2
```

`OwnerId`는 조종 권한, `Team`은 아군/적군 판정에 사용합니다. 미니언의 소유자는 0이며, 진영은 1 또는 2입니다. 같은 편 미니언과 다른 플레이어의 아군 유닛은 공격 대상으로 지정하지 않습니다. 시야에 보이는 미니언은 클릭하여 정보를 볼 수 있지만, 명령을 받는 선택 목록에는 내 소유 유닛만 포함합니다. 아군 우클릭은 이동, 적 미니언 우클릭은 공격입니다.

미니언은 전용 타입 `UnitMinionMelee`(100), `UnitMinionRanged`(101)이며, 기존 크기의 `MinionKnight.tscn` / `MinionArcher.tscn` 씬으로 표시합니다. 병영 유닛은 별도 타입 `UnitKnight`(1), `UnitArcher`(2)이며 약 30% 더 큰 `Knight.tscn` / `Archer.tscn`을 사용합니다. 서버 `unit_defs.go`는 용병(0~99), `minion_defs.go`는 하수인(100~199)을 정의하며, 영웅은 200~299 구역을 사용합니다. 각 등급의 정의를 합칠 때 서버가 Class를 지정하고 중복 번호를 검사합니다. 메시지 필드는 그대로이며 이동·공격 능력치는 각 정의에서 조절합니다. 미니언은 `Mover`·`Attack`만 가지며 `Production`·`Gather`가 없고 인구는 0입니다. 웨이브는 미니언 타입만 생성하고 병영은 미니언을 생산할 수 없습니다.

생성·라인 이동·적 탐색·전투는 서버가 처리하고, 클라이언트는 UNIT/POS/STATE/HP/STATS/REMOVE/HIDE를 적용합니다. 아군 미니언도 자신의 타입에 맞는 시야를 제공하며, 시야 밖 상대 미니언은 서버가 보내지 않습니다. HIDE로 숨긴 적은 다시 보일 때 최신 스냅샷으로 재생성합니다. [전장의 안개](fog-of-war.md)를 참고하세요. 별도의 클라이언트 웨이브 타이머나 미니언 생성은 없습니다. 미니언 타입 번호가 바뀌었으므로 서버와 클라이언트를 함께 갱신해야 합니다.

현재 서버는 첫 플레이어가 맵 동기화를 끝낸 뒤 30초부터, 30초마다 양쪽 진영의 상·하단 라인에 기사 3명 → 궁수 3명을 0.8초 간격으로 생성합니다. 늦게 접속한 클라이언트는 기존 미니언도 초기 스냅샷으로 받습니다.

미니언도 [공격 이동](attack-move.md)의 목표 재선택을 사용합니다. 첫 적을 추격하다가 공격 가능한 가까운 적을 만나면 그 적과 싸우고, 이미 사거리 안에서 공격 중인 상대는 유지합니다. 전투가 끝나면 기존 라인 경로로 복귀합니다.

## 편성 순서 변경

지휘관의 **미니언 UI**에서 초상화를 같은 라인의 원하는 칸 위로 드래그하면 그 위치에 끼워 넣습니다. 사이의 슬롯은 한 칸씩 밀리고, 비용은 없습니다. 클릭하면 기존 종류 교체 메뉴가 열리며 **+**는 슬롯 구매에 사용합니다. Esc·우클릭·패널 밖 드롭은 순서 변경을 취소합니다.

클라이언트는 `MINION_MOVE 라인 리비전 출발칸 도착칸`을 요청하고 새 `MINION_LANE`을 받은 뒤 화면을 갱신합니다. 라인·칸 번호는 0부터 시작합니다. 응답 대기 중에는 추가 편성 요청을 막고, 드래그 중 최신 편성이 도착하거나 역할이 바뀌면 드래그를 취소합니다. 변경된 순서는 다음 웨이브부터 계속 유지되고 현재 생성 중인 웨이브는 영향을 받지 않습니다. 서버도 함께 갱신해야 합니다.

미니언은 자기 라인에서 6m, 교전 시작 위치에서 12m 범위로 추격을 제한합니다. 미니언이나 대상이 허용 구역을 벗어나면 교전 시작점 근처의 라인으로 돌아가고, 복귀 지점 2m 안에 도착할 때까지 재추격하지 않습니다. 교전 중 목표를 바꿔도 시작점은 유지하며, 플레이어의 공격 이동에는 이 제한을 적용하지 않습니다. 서버만 갱신하면 적용됩니다. [원인·재현 결과와 현재 추격 규칙](../../project-w-server/README.md#라인-밖-영웅-추격-분석-2026-10-06)을 참고하세요.

`maps/test.json`은 서버의 파일을 바이트 그대로 복사했습니다. `lanes` 경유지와 `towers` 배치도 포함합니다. 클라이언트는 이 필드로 이동 계산이나 건물 생성을 하지 않지만, 맵 전체 원본 바이트로 해시를 구하므로 이 필드와 공백·줄바꿈도 양쪽에서 같아야 합니다. 맵 동기화 버전은 기존 `MAP 2`를 유지합니다. 미니언의 적 건물 공격도 기존 STATE/HP/REMOVE로 표시합니다.

검증:

- `tests/MinionSyncChecks.tscn`: 서버 없이 새 형식, 진영 판정, 조종 제한, 미니언 상태·삭제·재접속 검사.
- `tests/run.ps1 -Check MinionFormationChecks`: 서버 없이 실제 마우스 입력으로 편성 구매·드래그 순서 이동·취소·리비전 변경·영웅 역할 전환 검사.
- 실제 서버의 웨이브·피해·사망 판정은 클라이언트 기본 검증에서 제외합니다. 접속 검사는 별도 서버 검증 작업에서 진행합니다.
