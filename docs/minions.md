# 서버 미니언 동기화

현재 서버 메시지 형식은 다음과 같습니다. 이전의 진영 없는 WELCOME/UNIT 형식은 사용하지 않습니다.

```text
WELCOME 플레이어ID 진영
UNIT 타입 유닛ID 소유자ID X Z 진영
WELCOME 7 1
UNIT 0 15459 7 -60.00 0.00 1
UNIT 1 15464 0 -60.00 -6.00 1
UNIT 2 15480 0 60.00 -6.00 2
```

`OwnerId`는 조종 권한, `Team`은 아군/적군 판정에 사용합니다. 미니언의 소유자는 0이며, 진영은 1 또는 2입니다. 같은 편 미니언과 다른 플레이어의 아군 유닛은 공격 대상으로 지정하지 않습니다. 단일/박스 선택은 내 소유 유닛만 포함하므로 미니언에 이동·공격·채집 명령을 보내지 않습니다. 아군 우클릭은 이동, 적 미니언 우클릭은 공격입니다.

미니언은 기존 기사(type 1), 궁수(type 2) 씬으로 표시합니다. 생성·라인 이동·적 탐색·전투는 서버가 처리하고, 클라이언트는 UNIT/POS/STATE/HP/REMOVE를 적용합니다. 별도의 클라이언트 웨이브 타이머나 미니언 생성은 없습니다.

현재 서버는 첫 플레이어가 맵 동기화를 끝낸 뒤 30초부터, 30초마다 양쪽 진영의 상·하단 라인에 기사 3명 → 궁수 3명을 0.8초 간격으로 생성합니다. 늦게 접속한 클라이언트는 기존 미니언도 초기 스냅샷으로 받습니다.

`maps/test.json`은 서버의 파일을 바이트 그대로 복사했습니다. `lanes` 경유지와 `towers` 배치도 포함합니다. 클라이언트는 이 필드로 이동 계산이나 건물 생성을 하지 않지만, 맵 전체 원본 바이트로 해시를 구하므로 이 필드와 공백·줄바꿈도 양쪽에서 같아야 합니다. 맵 동기화 버전은 기존 `MAP 2`를 유지합니다. 미니언의 적 건물 공격도 기존 STATE/HP/REMOVE로 표시합니다.

검증:

- `tests/MinionSyncChecks.tscn`: 서버 없이 새 형식, 진영 판정, 조종 제한, 미니언 상태·삭제·재접속 검사.
- `tests/ServerConnectionChecks.tscn`: 실제 `127.0.0.1:7777` 서버에 접속하여 회관 2개·맵의 모든 포탑 배치, 내 일꾼 선택, 양쪽 기사·궁수 미니언 생성·이동·상태·체력·조종 제한을 검사합니다. 검증용 일꾼 한 기를 적 포탑에 보내 실제 공격 요청과 포탑의 발사·피해·사망 반영도 확인하므로 별도 검증 서버에서 실행하세요. 최대 45초 대기하며 종료 시 연결을 닫습니다.
