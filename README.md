석탄 연기가 하늘을 덮은 공업 지구에서 용병 회사들이 서로의 본부를 두고 싸웁니다. 연료도 사람도 태워야 회사가 굴러갑니다.

한 팀은 4명입니다. **대표**는 전장을 내려다보며 노동자를 부리고 기름을 퍼 올려 증기 병기를 찍어 냅니다. **용병** 셋은 라인 한가운데서 스킬로 싸우고, 마석을 차지해 공성추를 적 본진으로 보냅니다. RTS와 MOBA 장르가 맞물립니다.
