  <img src="docs/images/store/battle-1.gif" alt="라인 한가운데의 대규모 교전" width="100%">

석탄 연기가 하늘을 덮은 공업 지구에서 용병 회사들이 서로의 HQ를 걸고 싸웁니다. 연료도 사람도 할당량만큼 태워야 회사가 굴러갑니다.

한 팀은 4명입니다. **지휘관**은 전장을 내려다보며 일꾼을 부리고 기름을 퍼 올려 증기 병기를 찍어 냅니다. **영웅** 셋은 라인 한가운데서 스킬로 싸우고, 공물을 차지해 공성추를 적 본진으로 보냅니다. 같은 전장, 같은 시간에 RTS와 AOS가 맞물립니다.
