# 회관

`TownHall.tscn`은 3×3칸 본진용 회관 외형입니다. 석조 기단과 계단, 목조 벽, 푸른 슬레이트 지붕, 종탑, 깃발로 구성합니다. 시각 메시 전체가 X/Z -1.5~1.5 안에 들어가며, 바닥은 Y=0, 최대 높이는 약 4.345입니다. 정면과 입구는 -Z 방향입니다.

- `Visual`: 재질별 표면을 합친 정적 메시. 재질의 `banner`는 깃발과 문장을, `roof/roof_mid/roof_light`는 지붕을 표시합니다.
- `SelectionArea`: 물리 레이어 4(값 8)의 3×3 선택 영역입니다. 기존 유닛 선택 입력에는 아직 연결하지 않았습니다.
- `Entrance`: 입구 중심 표시점입니다. 유닛 생성 위치는 건물 점유 칸 밖에서 별도로 정해야 합니다.
- 루트의 `footprint` 메타데이터: Vector2i(3, 3).

`previews/TownHall.tscn`을 열고 F6으로 실행하면 서버 없이 볼 수 있습니다. 좌클릭 드래그로 회전하고 휠로 확대합니다. 바닥 격자는 1×1이며 금색 테두리는 3×3 범위입니다.

맵 원점이 칸 모서리를 뜻할 때, 시작 칸 (cx, cz)의 회관 중심은 `(originX + (cx + 1.5) * cellSize, 0, originZ + (cz + 1.5) * cellSize)`입니다. 현재 한 칸은 1단위이므로 기본 스케일 그대로 배치합니다. 양쪽 본진이 중앙을 향하게 하려면 각각 Y축 회전을 적용하세요.

이번 씬은 외형과 선택 영역만 포함합니다. 게임 맵 배치, 서버 건물 ID·체력·생산·3×3 통행 차단은 아직 연결하지 않았습니다.

재생성: 프로젝트 루트에서 `Godot --headless --path . --script tools/build_town_hall.gd`를 실행합니다. `TownHall.tscn`과 `meshes/TownHall.res`를 덮어쓰며 모델의 3×3 경계를 검사합니다. 디자인 치수와 색은 생성 스크립트에서 수정합니다.
